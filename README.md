# CodeAlpha Java Programming Internship Tasks

This repository contains the Java projects I completed during my **Java Programming Internship at CodeAlpha**.

All projects are console-based applications developed using **Java**.

## Projects

### 1. Student Grade Tracker

A console-based application for managing student grades.

**Features:**
- Add student names and marks
- Calculate average marks
- Find the highest and lowest marks
- Display a summary of student grades
- Uses `ArrayList` to store student data

**File:** `src/Task1_StudentGradeTracker.java`

---

### 2. AI Chatbot

A simple rule-based chatbot that interacts with users through the console.

**Features:**
- Responds to common questions
- Uses keyword matching
- Performs basic text processing
- Provides a default response for unknown inputs
- Continues chatting until the user enters `bye`

**File:** `src/Task2_AiChatbot.java`

---

### 3. Hotel Reservation System

A console-based hotel reservation system for managing room bookings.

**Features:**
- View available rooms
- Room categories: Standard, Deluxe and Suite
- Book a room
- Simulated payment process
- Cancel a reservation
- View booking details
- Saves booking information using File I/O

**File:** `src/Task3_HotelReservationSystem.java`
